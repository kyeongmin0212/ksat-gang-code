[작업 동작 특성]

  ✅ 컴퓨터 켜져 있을 때만 실행 (WakeToRun = False)
     → 잠자기/꺼짐 상태면 그 회차 스킵, 자동 wake 없음

  ✅ 시간 놓쳐도 따라가기 안 함 (StartWhenAvailable = False)
     → 19:00 에 컴퓨터 꺼져있었다면 다음날 19:00 까지 대기

  ✅ 배터리에서도 실행 (DontStopIfGoingOnBatteries)

  ✅ 인터넷 OFF 시 5분 대기 후 1회 재시도 (러너 내부 처리)
     → 그래도 OFF면 그 회차 종료 (다음날 다시 시도)

  ✅ 모든 출력 logs\scheduler.log 에 누적 (UTF-8)
     → tail 또는 메모장으로 확인 가능

  ✅ 단계 실패 시 즉시 중단 (rc 보존, 다음 단계 실행 X)

────────────────────────────────────────────────────────────────────
  문제 해결
────────────────────────────────────────────────────────────────────

  1) "PowerShell 실행 정책" 에러
     setup_scheduler.ps1 안 -ExecutionPolicy Bypass 로 우회됨.
     수동 실행 시: powershell -ExecutionPolicy Bypass -File ...

  2) 작업이 실행됐는데 결과 0xFFFFFFFF
     러너 안에서 종료 코드가 -1 → 보통 인터넷 미복구 / 환경변수 누락.
     logs\scheduler.log 확인.

  3) 환경변수가 작업에서 안 잡힐 때 (TG_BOT_TOKEN / TG_CHAT_ID)
     setx 로 등록했는지 + 새 PowerShell 로 setx 후 재로그인 1회.
     테스트: [Environment]::GetEnvironmentVariable("TG_BOT_TOKEN", "User")

  4) 한국 공휴일 / 주말 — KRX 데이터 없음
     collector.py daily 가 자동 스킵 (휴장일 인지)
     filter / strategy / calculator 도 빈 데이터 처리됨
